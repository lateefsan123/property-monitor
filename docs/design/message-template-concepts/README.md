# Message template concepts

Generated with the built-in imagegen tool. User selected 3, with the attachment ABOVE the message in the WhatsApp preview. Concepts use sample content, not saved account data.

## Implementation

Real component: `src/features/seller-signal/components/MessageTemplatesPanel.jsx`; existing save, upload, default and delete callbacks retained. Sidebar lists the user's actual templates. No fake entries, no new messaging features. Responsive stacked layout on narrow screens. Production deployment is separate.

## Verification

- Targeted ESLint and Vite production build passed; existing large-chunk warning remains.
- Actual component tested with isolated sample data at 1536x1024 and 390x844, not an authenticated account test.
- Verified selecting/editing/saving templates, setting a default, removing images, variable insertion, new-template creation and displaying validation errors through existing callbacks.
- Verified Escape closes the actions menu before the modal, Shift+Tab wraps within the dialog, image precedes message, and no page-level mobile overflow.
- Save callbacks were mocked to avoid changing the user's templates. Backend/upload services were not changed. Real upload/persistence still require authenticated verification.
- Development fixture produced a createRoot HMR warning before a fresh reload; this was fixture-specific, not the application entry point.
- `implementation.png` is the real component with sample data, not an imagegen render or production screenshot.

## Prompts used for imagegen

### 1

Use case: ui-mockup. Create one polished high-fidelity desktop web UI screenshot for Repeat AI message templates, 1536x1024 landscape. Extremely clean minimal white interface, near-black text, hairline neutral dividers, generous whitespace, elegant Inter-like typography, no gradients, no bright green chrome, no metadata labels, no stat cards, no marketing copy, no explanations outside the UI. Product functions: choose saved templates, create a template, rename, edit message with placeholders {{name}}, {{building}}, {{transactions}}, insert these variables, optional attached image with replace/remove, save changes, default selection and delete hidden in an ellipsis menu. Preview uses sample data, never an actual send. Main heading 'Message templates'. Selected name 'Transaction update'. Editor message verbatim 'Hi {{name}},\n\nHere are the latest sales in {{building}}:\n\n{{transactions}}\n\nWould you like an updated valuation?' Preview substitutes 'Hi Alex,' and 'Forte 2' and '2 bed · AED 2.9M · 992 sqft'. Use restrained pale sage only on WhatsApp message bubble. Show small optional apartment image attachment, not huge upload zones. Black Save button. A simple close X. Do not add Send buttons, scheduling, AI features, analytics, recipient management or unsupported variables. Preserve clear functional labels but eliminate explanatory paragraphs. Version 1: SPLIT COMPOSER. Wide centered modal with dim neutral app background. Header Message templates and X. Left 58% clean editor with compact saved template dropdown + plus, editable template name, generous textarea, small three token buttons directly below, slim image attachment row with thumbnail and replace/remove. Right 42% quiet WhatsApp preview with a single readable message bubble and image. Footer Save changes and ellipsis. No phone device frame.
